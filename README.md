## 🚀 How to Upload to GitHub & Host on Vercel

### Step 1: Initialize Git & Push to GitHub

1. Open PowerShell or Command Prompt in this folder (`C:\Users\Lenovo\.gemini\antigravity\scratch\elephant-beach-villa_build\`):
   ```bash
   git init
   git add .
   git commit -m "Initial production commit - Elephant Beach Villa"
   ```

2. Create a new repository on [GitHub](https://github.com/new) named `elephant-beach-villa`.

3. Link and push your code to GitHub:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_GITHUB_USERNAME/elephant-beach-villa.git
   git push -u origin main
   ```

---

### Step 2: Deploy to Vercel

1. Log in to [Vercel](https://vercel.com).
2. Click **"Add New Project"** → **"Project"**.
3. Select your GitHub repository (`elephant-beach-villa`).
4. Keep framework preset as **Other / Static Store**.
5. Click **"Deploy"**.

Vercel will build and publish your website instantly with a free SSL domain (e.g. `https://elephant-beach-villa.vercel.app`).
